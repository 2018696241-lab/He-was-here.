# 离线版隐私说明

本说明描述《人曾在此》1.0.0 离线 APK 的实际行为。发布者应在正式上架页面补充主体信息、联系渠道和生效日期。

- 游戏无需真实账号登录。剧情中的论坛、DOUDOU 用户名和密码均为虚构游戏内容。
- APK 不申请网络、通讯录、定位、相机、麦克风或外部文件读取权限，不接入广告或分析 SDK。
- 阅读进度、解谜状态、答题结果、设置与自行填写的笔记仅保存在应用本机存储，不发送至服务器。
- 通过菜单“重新开始”清除调查进度和旧备份，保留阅读设置。卸载应用或清除应用数据会删除全部本地存档。应用未启用 Android 云备份。
- 网页在线 AI 版是另一种运行模式，不属于本离线说明；其运营者需另外披露网络服务和数据处理方式。
