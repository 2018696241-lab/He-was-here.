# 发布指南

## 构建与打包

先完成 README 所列测试，再生成正式签名 APK。执行 `python tools/package_release.py` 将源码 ZIP、网页 ZIP、离线 HTML、APK 和 SHA256 清单写入源码目录旁的 `发布文件/`。

打包器采用文件白名单，排除签名、node_modules、构建缓存、验收截图和旧历史文件。网页包只包含游戏静态资源，不包含服务器密钥或运营记录。两个离线 HTML 应具有相同 SHA256。

## GitHub

上传源码 ZIP 解压后的内容，或在 `source/` 中初始化 Git。提交前查看 `git status`，确认没有任何密钥、签名配置、环境文件或本机 SDK 路径。CI 执行逻辑与浏览器测试；已有网页 AI 后端保持外部部署，`server-reference/` 仅作为继承代码参考。

本次没有自行设定开源许可证，需权利人决定代码、文案和素材是否允许公开及如何授权。

## TapTap 交接

准备内容：

- 正式签名 APK、应用名、包名、版本、图标和实际游戏截图。
- 简介建议：“从一台旧电脑出发，循着论坛旧帖与私人散文，寻找曾被留下的真相。”
- 操作说明：点击阅读、关键词搜索、黑白填格、七问回答；无强制得分门槛。
- 本地隐私说明见 `PRIVACY.md`；发布者补充真实主体和联系渠道。
- 素材授权、适龄和内容分级、资质及平台当次提审要求由发布者在官方开发者后台核实。

本次未调用 TapTap SDK、登录、支付、广告或统计服务，也未代为提审。不把签名私密包上传为玩家附件。若未来新增联网、统计、付费或广告，须同步修改权限、隐私说明与测试。

## 回退

原 rz10 目录保持不变。开发回退以源码版本为单位，勿混用不同版本的 `web/` 与生成 HTML。安卓不可简单降低 versionCode 覆盖安装；需要在旧逻辑基础上构建更高 versionCode、同签名的修复包，并保持存档兼容。
