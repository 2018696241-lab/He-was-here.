# 本版剧情档案

旧电脑的使用者是刘小周，后来登记名刘晓舟。他回到老宅，想弄明白小时候的空白、哥哥是谁，以及自己是不是被丢下了。

LINK求助帖通向天坛论坛。论坛保留英雄本色的连载与其他人的回帖。主线二“旧日往事”写到了周彤与弟弟，主线三写到克罗恩病，主线四关联仙枝怀慈菩萨和忠义堂。关于独生子女、旧法器、报纸、镜子和慧根二期楼盘的帖子彼此留下线索。

忠义堂公开介绍净濯大药，患者账户记载“接受净濯者：刘江海，患者反馈：不详”，并留下写着刘小周的袋签。这些标签会误导初读的人。第五、第六篇中镜子、眼睛、交换的叙述带有幻觉和不可靠视角，不能当成弟弟供血的证据。第七篇是绝望的告别，不能据此断言弟弟真的死了。

DOUDOU上五篇散文依次为《小屁孩》《小屁孩和袜子》《小屁孩肚子疼》《小屁孩的药》《小屁孩，哥哥不饿》。散文讲冲奶粉、袜子、病痛、找药、抽血以及纸船。事实是刘江海用自己的血换药给弟弟，袋签是受药者的名字。小周没有给哥哥供血。

李聚恒之弟李聚财已经去世。报纸留下讣告，散文也明确提到李聚财已经死了；“在国外”的说法与它们不符。

哥哥生日是一月二十八日。新稿的帖子日期与旧版年表不完全一致，本版不推断出生年份、年龄差或统一事件年份。不要引用旧医院档案或说玩家必须去医院网站，本版没有医院网站。

玩家找到的是旧字，不会因为解开密码突然恢复所有记忆。结局落在他知道自己不是被轻易丢下，而是被哥哥用力托住过。纸船和旧香烟上的留言是留下来的小事。不要将情节强行讲成鬼魂等待弟弟。
